# floatype の動き

floatype が打鍵から確定までに何をするかを、時間の順に書く。仕様（何を作るか、なぜ）は [spec.md](spec.md) にある。ここに書く数字は既定値で、どれも設定ファイル（`~/.config/floatype/config.txtpb`）か設定画面の floatype のタブで変えられる。括弧の中は設定の名前。

## 1. 打ってから確定するまで

「きょうはいいてんき」とローマ字で打ち、手を止め、Enter で確定する場合。

| 時刻 | 起きること | 画面 | インジケータ |
|---|---|---|---|
| 1 文字目 | かなが未確定の文字になる。予測候補の窓が出る。止まっていた zenz を別のスレッドで起こす（後述） | きょ | 入力中 |
| 2 文字目以降 | 読みが 2 文字（`live_conversion_min_chars`）に達し、ライブ変換が受け持つ | きょうは… | Mozc |
| 打つたびに | 前のライブ変換の結果を見せたまま、後ろに打ったかなを足す。予測候補を作り直す | 今日はいいて | Mozc |
| 最後のキーから 228ms（`live_conversion_delay_millisec`） | 手が止まったとみなし、読み全体を Mozc で変換し直す（ライブ変換）。zenz に聞く予約をする | 今日はいい天気 | Zenz… |
| 最後のキーから 500ms（`zenz_delay_millisec`） | zenz に読みと直前の文（最大 40 文字）を送る | 今日はいい天気 | Zenz… |
| その約 26ms 後（中央値、M4 Pro。90% は 77ms 以内） | zenz の答えが届く。下の「zenz の答えの扱い」で採るか決める | 採れば zenz の答え | 採れば Zenz、採らなければ Mozc |
| Enter | 見えているものを確定する | | 消える |

- 手を止めずに打ち続けている間は、ライブ変換も zenz も動かない。どちらも「最後のキーから」数える。
- 手を止めるたびに読み全体を変換し直す（Mozkey と同じ）。前に zenz が直した部分も、いったん Mozc の結果に戻り、zenz が答えるとまた直る。
- zenz の答えを 300ms（`zenz_timeout_millisec`）待っても来なければ捨て、Mozc の結果のままにする。
- 待つ間に別のキーを打つと、その依頼は取り消す（届いた答えも捨てる）。

### Space で変換するとき

- Space を押すとすぐ Mozc で変換し、同時に zenz に聞く（予約の待ちはない）。インジケータは Zenz… になり、答えで Zenz か Mozc に変わる。
- もう一度 Space で次の候補、候補の窓から選べる。zenz の補正の表示中に Space を押すと Mozc の結果に戻る。

### zenz の答えの扱い

届いた答えは、次のどれかに当てはまれば捨てて Mozc の結果のままにする。

- 長さの上限で途中で止まった
- 読みをかなのまま返した
- 利用者が打った数字や英字（読みに入っている 2026、gpt-5 など）を、Mozc の結果にあるのに変えた
- Mozc の候補を組み合わせて書けない（zenz の答えは必ず Mozc の候補のどれかで書ける形にする）
- Mozc と同じだった

捨てなければ、各文節の候補を zenz の答えに合わせて並べ替えて見せる（Zenz）。数字や記号の全角・半角は Mozc の書き方を残す。

### 確定の前後の操作

| 操作 | 動き |
|---|---|
| Ctrl+z（ことえり配列） | その場で zenz に聞く（手動の補正） |
| 補正の表示中に Ctrl+Delete | その補正を止め、同じ読みでは二度としない（`zenz_learning`） |
| 確定の直後の Backspace、Ctrl+Backspace | 確定で覚えたことを戻す（文字はアプリが消す） |
| zenz の補正をそのまま確定 | 覚えて、次に同じ読みでは zenz を待たずにすぐ出す |

## 2. インジケータ

未確定の文字の上（`indicator_style.placement`、ABOVE）、5 ポイント離して（`gap`）出す。縦書きでは列の横に出す。

| 表示 | 意味 | 背景の色 |
|---|---|---|
| 入力中 | 読みを打っている（ライブ変換が受け持つ前） | #747d8c |
| Mozc | Mozc の結果を見せている。ライブ変換が受け持ってから（手を止める前から）この表示 | #586b85 |
| Zenz… | zenz に聞く予約をしてから答えが来るまで。ライブ変換なら手を止めてから最大で約 0.3 秒 | #847438 |
| Zenz | zenz の補正を見せている | #338d85 |

- zenz の答えが Mozc と同じ、捨てた、時間切れのときは Mozc に戻る（Mozkey と同じ）。
- 形は角丸の帯（PILL）。高さ 22、幅は文字に合わせて 56 から広がる。文字は白、システムフォント 11 ポイントの Medium。不透明度 93%。
- 文字の左に 5×5 の丸を、文字の色（不透明度 85%）で描く。背景は上が 11% 明るいグラデーション。どちらも Mozkey に合わせた。
- 日英混在入力（`mixed_english`）がオンのときは、右端に あ か A を足す。
- 形・文字・位置・色・大きさは `indicator_style` で変えられる。`show_indicator` で消せる。

## 3. 予測候補と変換候補

- 打っている途中に、番号なしの小さな一覧（予測候補）を出す。Mozc の辞書の語と、入力の履歴から出す。
- 足した辞書（人名、地名、SudachiDict、ニコニコ大百科と pixiv 百科事典の語）の語は、最後まで打って変換すれば出るが、予測候補には出さない。数文字打ったところに知られていない語が出るのを防ぐため。ニコニコと pixiv の両方にある語（草生える など）は予測候補にも出す。
- 手を止めてライブ変換が動いたあとも、予測候補の窓を残す（Mozkey と同じ）。zenz が補正しても残る。手を止める直前に出ていた一覧をそのまま残すので、直前に出ていなければ出ない。
- 予測候補はクリックで選べる。Tab か ↓ で一覧に入り、番号や矢印で選んで Enter で確定する。数字キーをそのまま打つと読みに入る（手を止めたあとに数字を打てるように。Mozkey も同じ）。
- Space を押すと変換候補の窓（番号つき）になる。

## 4. zenz の採点プロセス

- zenz（zenz-v3.2-small）は別のプロセス（`floatype_scorer`）で動く。CPU だけを使い、ネットワークに触れない。
- 1 分間依頼が無ければ自分で終わり、メモリを返す（`zenz_stop_when_idle`）。次に打った 1 文字目で、キーの処理とは別のスレッドで起こす。起きるまで約 65ms で、手を止めて zenz に聞くまでの約 0.5 秒に間に合う。キーは待たない。
- 動いている間のメモリは約 100MB（floatype 全体で約 145MB）。`zenz_low_memory` をオンにすると、CPU 向けに並べ替えた重みの複製を持たず約 36MB（全体で約 87MB）になるが、zenz の答えまで約 2 倍（中央値 26ms → 50ms）かかる。
- 止まっているときの floatype 全体は約 51MB。

## 5. 句読点で確定する（オフが既定）

`use_direct_commit` をオンにすると、`direct_commit_characters`（既定 、。？！「」）を打ったところで、入力中の文を変換して zenz の答えを待ち（最大 300ms）、そのまま確定する。待っている間の Enter はその場で確定、ほかのキーは見えているものを確定してから効く。

## 6. そのほかの入力の動き（どれもオフが既定）

- 日英混在入力（`mixed_english`）：かなの入力中に打った英単語を、変換で英字（半角）のままにする。英単語とみなすのは、ローマ字がかなにならずに英字が残り、英単語一覧 SCOWL にある 3 文字以上の語。
  - 文の途中でも単語ごとに見る。「きょうは update する」は 今日はupdateする、「update を」は updateを になる。
  - 手を止めた（ライブ変換）か Space で変換したときに、その語を打ったとおりの英字に置き換える。そのあと打つかなは、英字のあとに かな で続く。Backspace は英字を 1 字ずつ消す。
  - 英単語の最後の子音が次のかなとつながったときも拾う（test + する は てsつる、email + を は えまいlwお と出るが、testする、emailを になる）。
  - 音の途中で手を止めたとき（きょうは + s が has と読める）は、英字で見せるが、次に英字のキーを打つと打ったとおりに戻す（きょうはしる）。子音で終わる英単語（email、keyboard）も同じで、続けて を を打つと emailを になる。
  - 拾えないもの：ローマ字が全部かなになる語（online、video、chat + する など）。英字が残らないので日本語と区別できない。前のかなとつながって別の英単語になる場合（きょうは + test は hates と読める）。
  - インジケータの右端は、キャレットの直前の語が英字なら A、それ以外は あ。
- 曖昧なローマ字の途中表示（`display_ambiguous_romaji`）：長い規則の途中のローマ字を、いまの時点の かな で見せる（n は ん）。
- ライブ変換のルビ（`live_conversion_ruby`）：ライブ変換の上に読みを小さく出す。
- zenz を待ってから表示（`live_conversion_waits_for_zenz_millisec`）：手を止めたとき、Mozc の結果を先に出さず、zenz の答えを最大この時間待ってから 1 度だけ出す。

## 7. 辞書

Mozc の辞書に、ビルドのときに作る辞書を足す（`floatype/tools/make_extra_dictionary.py`、`update.sh` が呼ぶ）。足すのは Mozc に無い語だけで、Mozc がもう知っている読みには費用を上乗せし、Mozc の答えを押しのけないようにする。

| 辞書 | 語数 | 出どころ |
|---|---|---|
| 日付と時刻 | 472 | 数え方の規則から作る（`make_time_words.py`） |
| 人名 | 24,180 | mozcdic-ut-personal-names |
| 地名 | 約 16 万 | mozcdic-ut-place-names（郵便番号データ） |
| 一般の語 | 約 67 万 | mozcdic-ut-sudachidict（SudachiDict） |
| ネットの語 | 約 3 万 3 千 | dic-nico-intersection-pixiv |

語の出やすさ（費用）は、日本語版 Wikipedia の記事名のうちその語で始まるものの数で決める。
